# Backend

| Part | Technology | Contents |
|---|---|---|
| Agent layer | Mastra.ai, TypeScript | **Conversational Agent** (supervisor) and **Founder Roadmap Agent** (delegated agent-tool) |
| ML/AI services | Python, FastAPI | Survival Prediction Model, Explainability Engine (XAI), Idea Similarity Engine |
| Storage | Supabase | Application data and vector embeddings |

**Conversational Agent tools:** Survival Prediction Model · Explainability Engine · Idea Similarity Engine · market-indicator retrieval · Founder Roadmap Agent

**Founder Roadmap Agent tools:** regulatory retrieval · requirement sequencing & prioritization · roadmap visualization

The LLM (OpenAI API) is used only inside the agent layer.
