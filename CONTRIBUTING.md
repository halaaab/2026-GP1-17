# Working Conventions

Put the Jira issue key in branch names, commit messages, and PR titles so the work appears on the Jira issue.

- Branch: `KEY-12-short-description`
- Commit: `KEY-12 Add founder sign-up form`
- PR title: `KEY-12 Founder sign-up`

Replace `KEY` with our Jira project key. `main` stays demo-ready: work on branches and merge via pull request.
