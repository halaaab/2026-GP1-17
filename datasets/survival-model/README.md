# Survival Model Dataset

Historical company-level startup data prepared for survival analysis and prediction.

- **Used by:** Survival Prediction Model and Founder Intelligence Score
- **Proposed sources:** Zid or Crunchbase
- **Format:** Structured startup and company-history records
- **Status:** Source under evaluation

The final dataset may include company characteristics, funding history, operating status, sector, location, and other validated model features.

No production dataset should be added until the source and usage rights are confirmed.
