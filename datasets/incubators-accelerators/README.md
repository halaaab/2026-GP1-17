# Incubators and Accelerators Dataset

Validated profiles of incubators, accelerators, and entrepreneurship-support organizations.

- **Used by:** Incubators & Accelerators Explorer
- **Sources:** EcosystemSA and publicly available entrepreneurship websites
- **Format:** Structured organization and program records
- **Status:** Validated initial dataset

The dataset supports discovery and comparison of entrepreneurship programs. Current program details should be verified against the organization’s official website.

Missing values are left blank and are not inferred.
