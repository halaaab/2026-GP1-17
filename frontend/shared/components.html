Page layout

The sidebar, header and footer are built by layout.js. A page picks one with data-layout on <body> and writes only its own content inside <main>. Copy pages/_template/ to start a new page.

data-layoutWhat the page getsUsed by
founderSidebar, header, language switchChatbot, explorers, profile
adminAdmin sidebar, breadcrumb headerAdmin console pages
publicTop bar with links, footerLanding page
authLogo and a centered cardSign up, log in, reset password

Every founder and admin page also loads shared/guard.js. It sends away anyone who is not signed in with the right kind of account, shows the person's name in the sidebar, and makes the logout button work. A founder page that visitors may also open (the explorers) adds data-access="public" to <body>.
